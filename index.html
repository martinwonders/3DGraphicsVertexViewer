    How this works

    A vertex is six floats: position x, y, z and colour r, g, b. sc_VertexData[] holds these records; indices start at 0.

    sc_IndexData[] holds unsigned 16-bit indices. Every three consecutive indices name one triangle, and each index points at a whole vertex record — position and colour.

    Winding: viewed from the front, the three corners run anticlockwise. That side is the front face; the back face is culled by default, so a triangle wound the wrong way vanishes from this side.

    Same cube, two ways: 8 corner positions never changes — but a cube with independent per-face colours needs 24 vertex records (each corner appears three times with different colours), whereas shared per-vertex colours need only 8 records and let colour interpolate across each triangle.

    Right-handed axes: +X right, +Y up, +Z towards you.

        Controls & keyboard
        
    
          
    Orbit: drag in the viewport. Zoom: scroll or pinch. Tab into any table and edit with the keyboard. Ctrl+Z / Ctrl+Y undo and redo. Editing never moves the camera; use Fit model when you want it reframed.
